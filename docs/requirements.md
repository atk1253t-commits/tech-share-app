# TechShare 要件定義メモ

## 1. 機能一覧（6つ）
1. 記事一覧表示：登録された技術記事をカード形式で一覧表示する
2. 記事検索：キーワードで記事を検索する（タイトル・本文ヒット、大文字小文字区別なし、0件時のメッセージ表示）
3. 記事詳細表示：記事の全文・投稿者・作成日を表示する（Markdown整形表示）
4. 記事作成：新規記事を作成して一覧に追加する（Markdownのリアルタイムプレビュー付き）
5. 記事編集・削除：ログイン中の投稿者本人が記事を編集・削除する（編集時は元の作成日を保持、削除時は確認ダイアログを表示）
6. 認証状態管理（ログイン・ログアウト）：ログイン状態に応じてヘッダー表示・操作ボタン表示・作成画面へのアクセスを制御する

## 2. 記事のデータ項目（5つ）
1. id：記事を識別する一意のID
2. title：記事のタイトル
3. author：投稿者名
4. content：記事の本文（Markdown形式）
5. createdAt：記事の作成日

## 3. APIエンドポイント（5本）
1. GET /articles：記事一覧を取得する
2. GET /articles/:id：指定したIDの記事詳細を取得する
3. POST /articles：新規記事を作成する
4. PUT /articles/:id：指定したIDの記事を更新する
5. DELETE /articles/:id：指定したIDの記事を削除する
